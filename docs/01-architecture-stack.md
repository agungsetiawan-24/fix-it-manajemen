# 01. ARSITEKTUR & TECH STACK

## Tech Stack Pilihan
- **Frontend:** Blade / Inertia / React / Tailwind CSS
- **Backend:** Laravel 12/13 (PHP 8.3+)
- **Database:** MySQL / PostgreSQL
- **Real-time Sync:** WebSockets / Polling

## Aturan Penulisan Kode (Coding Standards)
- Mengikuti kaidah PSR-12 dan Laravel Best Practices.
- Error handling terstruktur dengan logging dan status code HTTP yang tepat.
